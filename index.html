WHAT THIS RUN CAN TELL YOU

Start with the easy world. Then change its rules.

The adaptive bank is the important control: it has exactly the same routing and records, with writing left enabled.

224 bytes of numeric state per learner. Includes record matrices, context centers and write counts, or 28 shared-model coefficients. Excludes JavaScript object overhead, global bookkeeping and scratch memory. No replay buffer.

This is an inspectable toy, not a claim to have solved continual learning. The cues are hand-designed to be informative. Freezing happens after a fixed number of writes; permission to write is not learned. Read the protocol ↗
